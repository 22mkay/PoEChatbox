# PoEChatbox
**Author:** Mikhulu Kamogelo Flatela (ST10483373)
**Institution:** IIE Rosebank International

## Overview
PoEChatbox is a Java console application developed for a Portfolio of Evidence submission. It features robust user authentication and a secure messaging system that generates unique message IDs and cryptographic hashes.

## Features
* **User Registration & Login:** Enforces password complexity, username constraints, and mobile number validation.
* **Secure Messaging:** Generates unique alphanumeric IDs and message hashes.
* **Local Storage:** Appends formatted message records to a local JSON file.
* **Automated Testing:** CI/CD pipeline integrated via GitHub Actions running 23 automated JUnit 4 tests.

## Tech Stack
* Java 17
* Apache Maven
* JUnit 4.13.2
